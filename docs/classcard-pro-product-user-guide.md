# ClassCard Pro Product Guide and User Guide

## Overview

ClassCard Pro is a premium student management SaaS platform for tuition centers, schools, academies, and training institutes. It combines institute administration, student records, teacher management, class scheduling, enrollment, attendance, payments, learning tools, notifications, reports, parent/student access, and mobile attendance workflows in one system.

The platform is built for multi-branch institutes that need a structured way to manage daily operations, reduce manual work, improve fee collection visibility, and give students, parents, teachers, and administrators a clear digital experience.

## Key Points

- Centralized management for institutes, branches, students, parents, teachers, courses, classes, enrollments, attendance, payments, homework, quizzes, live classes, notices, and reports.
- Role-based access for super admins, institute admins, branch admins, teachers, staff, students, and parents.
- Attendance can be marked manually, by NFC card, or by secure QR token.
- Payment management includes invoices, dues, partial payments, ledgers, receipts, reports, and CSV export.
- Student and parent portal provides self-service access to classes, attendance, payments, notices, and receipts.
- Mobile staff app supports classroom attendance workflows with NFC, QR scanning, manual marking, and student quick views.
- Student mobile app supports dashboard, courses, attendance, payments, homework, quizzes, live classes, notifications, and profile access.
- Learning tools include homework, submissions, quizzes, course materials, live class scheduling, recordings, and provider integrations.
- Reporting dashboards help institute owners and staff track attendance, revenue, dues, student activity, and operational performance.
- The system supports SaaS packaging with subscription plans, student limits, teacher limits, branch limits, billing status, and admin oversight.

## Main Modules

### 1. Dashboard

The dashboard gives staff and administrators a quick operational view of the institute. It includes summary metrics, recent activity, charts, attendance trends, payment performance, and shortcuts into daily workflows.

### 2. Student Management

Student management stores student profiles, admission numbers, branch assignment, guardian details, contact information, status, NFC UID, QR/attendance token, assigned classes, attendance summaries, and payment summaries.

### 3. Teacher Management

Teacher management stores teacher profiles, contact details, specialties, branch assignment, linked user accounts, assigned classes, and teaching responsibilities.

### 4. Course and Class Management

Courses define the learning product or subject, while classes define the actual scheduled class groups. Class records can include course, teacher, branch, timetable, room, capacity, enrolled students, homework, quizzes, materials, attendance sessions, and live classes.

### 5. Enrollment Management

Enrollment connects students to class groups. Staff can manually assign students, bulk assign students, activate or deactivate enrollments, and remove students from classes when needed.

### 6. Attendance Management

Attendance supports classroom sessions with statuses such as present, absent, late, and excused. Attendance can be captured through manual entry, NFC card tap, QR token scan, and bulk operations. Audit logs record attendance actions for traceability.

### 7. Payment Management

Payments cover monthly fees, admission fees, exam fees, and other fees. The module supports pending, paid, partial, overdue, and cancelled statuses, along with discounts, balances, due dates, payment methods, printable receipts, student ledgers, finance dashboards, payment reports, and CSV exports.

### 8. Homework

Teachers and staff can create homework for classes, publish assignments, attach external links or files, monitor submissions, review work, award marks, and provide feedback.

### 9. Quizzes

Quiz tools support draft, published, and closed quizzes. Question types include multiple choice, true/false, short answer, and essay. The system supports attempts, scoring, auto-marked results, manual review, pass marks, time limits, and quiz reports.

### 10. Course Materials

Course materials can be shared as links, files, videos, or notes. Materials can be connected to courses or class groups for student access.

### 11. Live Classes

Live class management supports scheduled online classes, providers such as Google Meet, Zoom, YouTube Live, Jitsi, LiveKit, and other external links. Live classes can be free or paid, can track attendance, and can store recordings.

### 12. Notifications and Notices

Admins, staff, and teachers can send notices to the whole institute, selected classes, or selected students. Notification types include notices, payment due reminders, absent alerts, class notices, and receipts.

### 13. Reports

Reports help institutes review attendance, payments, dues, class activity, learning activity, quiz performance, and operational metrics. Report views are designed to support decision-making and follow-up action.

### 14. Settings

Institute settings include receipt prefix, receipt footer, payment due day, attendance late threshold, currency, theme color, branch settings, and other configuration values.

### 15. Billing and Subscription

The billing area supports SaaS-style subscription management with plans, subscription status, limits for students, teachers, branches, SMS credits, monthly pricing, and period tracking.

### 16. Super Admin

Super admins can manage and oversee the broader SaaS environment, including institutes, subscriptions, platform-level activity, and system administration.

## User Roles

### Super Admin

Super admins manage the SaaS platform itself. They can access platform administration, view global dashboards, and oversee institutes and subscription health.

### Institute Admin

Institute admins manage the full institute account. They can configure settings, manage branches, students, teachers, classes, payments, learning tools, reports, notifications, billing, and institute-level workflows.

### Branch Admin

Branch admins manage branch-level operations. They can work with students, teachers, classes, enrollment, attendance, homework, quizzes, live classes, notifications, reports, and branch settings depending on permissions.

### Teacher

Teachers can access assigned class workflows, including students, classes, attendance, homework, quizzes, live classes, reports, and notifications.

### Staff

Staff users support operational work such as student management, enrollment, attendance, payments, notifications, and reporting.

### Student

Students access their portal or mobile app to view courses, attendance, payments, homework, quizzes, live classes, notifications, and profile details.

### Parent

Parents access the family portal to view linked student information, classes, attendance, payments, receipts, and notices.

## Common Use Cases

### Tuition Center Daily Operations

A tuition center can manage student records, assign students to class groups, track attendance for each session, record payments, print receipts, and review dues from one dashboard.

### Multi-Branch Institute Management

An institute with several branches can separate branch-level users, students, teachers, and classes while still keeping institute-level reporting and administration centralized.

### NFC Student Attendance

Students can be issued NFC cards. Staff or teachers start an attendance session, tap each student card with the mobile attendance app or compatible terminal flow, and the system marks attendance using the saved NFC UID.

### QR Attendance

Students can use a secure QR code linked to their attendance token. Staff can scan the QR code during a class session and mark the student as present, late, absent, or excused based on the workflow.

### Manual Attendance Backup

When a card is missing or a device cannot scan NFC/QR, staff can manually mark attendance from the class list.

### Fee Collection and Dues Follow-Up

Administrators can create payments, record full or partial payments, monitor balances, identify overdue students, print receipts, and export payment reports.

### Parent Communication

The institute can publish notices to the full institute, a class, or selected students. Parents and students can view relevant notices through their portal or app.

### Digital Learning Support

Teachers can publish homework, review submissions, run quizzes, schedule live classes, and share learning materials through the same platform used for administration.

### Online Class Delivery

An institute can schedule paid or free live classes, connect external meeting providers, track student joins, and store recordings for future access.

### SaaS Resale or White-Label Foundation

The platform can serve as a foundation for a commercial SaaS product with subscriptions, institute onboarding, plan limits, billing, role-based access, and multi-tenant data organization.

## Web User Guide

### 1. Sign In

1. Open the web app.
2. Go to the login page.
3. Enter your email and password.
4. After login, the system redirects you based on your role.

Demo login after seed data:

```text
Email: admin@classcard.test
Password: ClassCard@2026
```

### 2. Register a New Institute

1. Go to the register page.
2. Enter institute information and admin account details.
3. Submit the form.
4. Sign in using the newly created admin account.
5. Configure institute settings before adding operational data.

### 3. Configure Institute Settings

1. Open Settings.
2. Review receipt prefix and receipt footer.
3. Set the payment due day.
4. Set the attendance late threshold.
5. Select currency and theme color.
6. Save changes.

### 4. Add Teachers

1. Open Teachers.
2. Select the add teacher action.
3. Enter teacher name, email, phone, branch, and specialty.
4. Save the teacher profile.
5. Assign the teacher to class groups when creating or editing classes.

### 5. Add Students

1. Open Students.
2. Select the add student action.
3. Enter admission number, name, contact details, branch, and status.
4. Add guardian or parent details where applicable.
5. Add NFC UID if the student will use an NFC card.
6. Save the student profile.

Example NFC UID from demo data:

```text
NFC-DEMO-0001
```

### 6. Create Courses and Classes

1. Open Classes.
2. Create or select a course with name, code, subject, grade, description, and fee.
3. Create a class group with class name, code, schedule, room, capacity, branch, course, and teacher.
4. Save the class group.
5. Review enrolled students and related class activity from the class detail page.

### 7. Enroll Students

1. Open Enrollment.
2. Select the class group.
3. Choose one or more students.
4. Assign students manually or in bulk.
5. Use active or inactive status to control current enrollment.
6. Remove enrollments when a student leaves a class.

### 8. Mark Attendance

1. Open Attendance.
2. Select the class group and session date.
3. Start or continue an active attendance session.
4. Mark students manually, scan QR tokens, or use NFC UID marking.
5. Review attendance status for each student.
6. Save or confirm the session results.
7. Check attendance reports for daily, class, or student-level summaries.

Attendance statuses:

- Present
- Absent
- Late
- Excused

Attendance sources:

- Manual
- QR
- NFC
- Bulk

### 9. Mark Attendance by NFC API

Use this backend endpoint when integrating an NFC reader or testing attendance from an API client:

```http
POST /api/attendance/nfc
Content-Type: application/json

{
  "classGroupId": "class_id",
  "nfcUid": "NFC-DEMO-0001",
  "status": "PRESENT"
}
```

### 10. Mark Attendance by QR API

Use this backend endpoint when integrating QR attendance:

```http
POST /api/attendance/qr
Content-Type: application/json

{
  "classGroupId": "class_id",
  "token": "student_attendance_token",
  "status": "PRESENT"
}
```

### 11. Manage Payments

1. Open Payments.
2. Review the finance dashboard for paid, pending, partial, and overdue amounts.
3. Open a student payment ledger to see invoices and balances.
4. Create or update a payment.
5. Add discount, paid amount, due date, method, and notes where required.
6. Save the payment.
7. Print or view the receipt.
8. Use Dues to follow up on unpaid balances.
9. Use Reports to review payment performance and export CSV data.

Payment types:

- Monthly fee
- Admission fee
- Exam fee
- Other

Payment methods:

- Cash
- Card
- Bank transfer
- Online

### 12. Publish Notices and Notifications

1. Open Notifications.
2. Create a notice.
3. Select the audience: institute, class, or selected students.
4. Enter title and message.
5. Publish immediately or schedule with a publish date.
6. Review notification logs and delivery status where available.

### 13. Create Homework

1. Open Homework.
2. Create a new homework item.
3. Select class group and course if applicable.
4. Enter title, description, deadline, marks, and attachments or links.
5. Save as draft or publish.
6. Review student submissions.
7. Award marks and provide feedback.

### 14. Create Quizzes

1. Open Quizzes.
2. Create a new quiz.
3. Select class group and optional course.
4. Set start time, end time, time limit, total marks, pass mark, and attempt limit.
5. Add questions and answers.
6. Publish the quiz.
7. Review attempts, auto-marked scores, manual scores, and reports.

### 15. Manage Live Classes

1. Open Live Classes.
2. Configure provider credentials or integrations where required.
3. Create a new live class.
4. Select class group, teacher, provider, meeting link, start time, end time, and access type.
5. Publish the live class.
6. Students can join from their portal or app.
7. Review attendance and add recordings when available.

### 16. View Reports

1. Open Reports.
2. Select the report area or filters.
3. Review tables, metrics, and charts.
4. Export data where export actions are available.
5. Use report findings to follow up on absences, overdue fees, class performance, or student progress.

## Staff Mobile Attendance App Guide

The staff mobile app is designed for teachers and staff who need to mark classroom attendance from an Android device.

### Main Mobile Features

- Staff login with secure token storage.
- Dashboard with today's classes, active sessions, pending dues, and recent scans.
- Branch and class selection.
- Start or continue attendance sessions.
- NFC attendance using Android NFC hardware.
- QR attendance using device camera.
- Manual attendance marking.
- Student quick view with attendance and payment context.

### Configure the Mobile App

1. Run the web backend on a LAN-visible host.
2. Set the mobile app API URL to your computer LAN IP.
3. Use a URL similar to:

```text
http://YOUR_LAN_IP:3000
```

For local development, create `apps/mobile/.env`:

```env
EXPO_PUBLIC_API_URL=http://192.168.1.10:3000
```

Use your actual LAN IP. Do not use `localhost` when testing on a physical phone.

### Staff Mobile Workflow

1. Sign in with a staff, teacher, branch admin, institute admin, or super admin account.
2. Select the branch and class.
3. Start or continue an attendance session.
4. Choose NFC, QR, or manual attendance.
5. For NFC, tap the student's NFC card on the device.
6. For QR, scan the student's QR code.
7. For manual attendance, select the student and status.
8. Open Student Quick View when you need payment and attendance context.
9. Return to the dashboard to continue another class session.

### NFC Notes

- Android is the recommended first testing target for NFC.
- The mobile app requires an Expo Dev Build because Expo Go does not support the required native NFC capability.
- The device must have NFC hardware enabled.
- Each student's NFC UID must be saved in the student profile before NFC attendance can work.

1. Admin reviews dashboard metrics.
2. Staff checks today's classes and pending dues.
3. Teachers prepare attendance sessions, homework, quizzes, or live classes.

### During Classes

1. Teacher or staff opens the class attendance session.
2. Students are marked present by NFC, QR, or manual entry.

1. Attendance reports are checked.
2. Absent students can be followed up through notifications.

1. Admin reviews attendance and revenue summaries.
2. Staff exports or reviews payment reports if needed.
3. Notices are sent for upcoming classes, dues, absences, or institute announcements.
4. Managers check unresolved dues, pending submissions, and upcoming live classes.

## Implementation and Setup Guide

### Requirements

- Node.js and npm.
- MySQL database.
- Next.js-compatible environment.
- Android device with NFC for mobile NFC testing.

### Install Dependencies

```bash
npm install
```

### Configure Environment

Create `.env` from `.env.example`:

```bash
cp .env.example .env
```

Set the main values:

```env
DATABASE_URL="mysql://root:password@localhost:3306/classcard_pro"
NEXTAUTH_URL="http://localhost:3000"
NEXTAUTH_SECRET="replace-with-a-long-random-secret"
```

### Create the Database

```sql
CREATE DATABASE classcard_pro CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### Prepare Prisma and Seed Data

```bash
npm run prisma:generate
npm run prisma:push
npm run seed
```

### Start the Web App

```bash
npm run dev
```

### Common Prisma Commands

```bash
npm run prisma:generate
npm run prisma:push
npm run prisma:migrate
npm run prisma:studio
npm run seed
```

### Useful Quality Commands

```bash
npm run lint
npm run typecheck
npm run build
```

## Operational Best Practices

- Create branches before adding branch-specific students, teachers, and classes.
- Keep admission numbers unique and consistent.
- Save NFC UIDs only after verifying the card or tag reads correctly.
- Use QR tokens as a secure fallback when NFC is unavailable.
- Record payment discounts and partial payments immediately to keep balances accurate.
- Review overdue payments regularly from the dues screen.
- Publish homework, quizzes, and live classes with clear dates and deadlines.
- Use role-specific accounts instead of sharing admin credentials.
- Review reports weekly to catch attendance drops, unpaid balances, and inactive students.
- Keep provider credentials and integration secrets restricted to admin users.

## Glossary

- Institute: The main organization using the platform.
- Branch: A physical or operational location under an institute.
- Course: The subject or paid learning product.
- Class Group: A scheduled class connected to a course, teacher, branch, and group of enrolled students.
- Enrollment: The link between a student and a class group.
- Attendance Session: A date-based class attendance event.
- NFC UID: The unique ID stored on or read from a student's NFC card or tag.
- QR Token: A secure student attendance token used for QR-based attendance.
- Ledger: A student's payment history, invoices, paid amounts, balances, and receipts.
- Notice: A message sent to institute, class, or selected student audiences.
- Live Class: An online class session delivered through a meeting provider or external link.
